seadata

Data server for the Leeway sailing app. Forecasts, seamarks, chart packs and AIS in one place, cached.

  • GET /v1/info: what this server offers
  • GET /v1/forecast?points=45.32,14.44;44.53,14.47: hourly wind (finest model per hour), gusts, waves, swell, currents, weather
  • GET /v1/wind-grid?west=13&south=44&east=15&north=46: wind on a grid for map arrows
  • GET /v1/tiles/seamark/{z}/{x}/{y}.png: OpenSeaMap seamark tiles
  • GET /v1/charts and /v1/charts/files/{name}: offline chart packs
  • GET /v1/ais?west=13&south=44&east=15&north=46: live vessels (if configured)
