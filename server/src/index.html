seadata

Data server for the Leeway sailing app. Base map, depth, forecasts, seamarks, chart packs, warnings and AIS in one place, cached for every user.

  • GET /v1/info: what this server offers
  • GET /v1/forecast?points=45.32,14.44;44.53,14.47: hourly wind (finest model per hour), gusts, waves, swell, currents, weather
  • GET /v1/wind-grid?west=13&south=44&east=15&north=46: wind on a grid for map arrows
  • GET /v1/tiles/seamark/{z}/{x}/{y}.png: OpenSeaMap seamark tiles
  • GET /v1/charts and /v1/charts/files/{name}: offline chart packs
  • GET /v1/ais?west=13&south=44&east=15&north=46: live vessels (if configured)
  • GET /v1/tiles/base.json, /v1/tiles/base/{z}/{x}/{y}.pbf, /v1/fonts/{fontstack}/{range}.pbf: worldwide vector base map
  • GET /v1/tiles/bathy/{z}/{x}/{y}.pbf: worldwide depth areas and contours
  • GET /v1/tiles/satellite/{z}/{x}/{y}.jpg: Sentinel-2 imagery
  • GET /v1/radar: rain radar frames
  • GET /v1/sealevel?lat=45.33&lon=14.42: tide and surge
  • GET /v1/warnings?west=13&south=42&east=19&north=46: official weather warnings
  • GET /v1/search?q=punat: harbours, anchorages and places
  • GET /metrics: cache and upstream statistics
